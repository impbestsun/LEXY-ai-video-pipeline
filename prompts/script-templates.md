# 脚本与分镜提示词模板（Gate 1/2 · 大语言模型）

工具：本地 Ollama/Qwen 或 WorkBuddy Agent。输出必须结构化，直接落入 `script.md` / `storyboard.md`。

## 1. 脚本生成 Prompt

```
你是莱克电气的短视频编剧，为【{产品名}】写一条 30 秒抖音短视频脚本。
目标人群：{人群}；核心卖点：{卖点1、卖点2}；场景：{场景}。

硬性要求：
1. 前 3 秒 hook 必须包含冲突/悬念/明确利益点之一，禁止平铺直叙开场
2. 人设：小资中产都市女性/男性，25-35 岁，生活讲究但不炫富；禁止穷苦人设
3. 卖点出现顺序按转化权重排序，每条卖点配一个生活场景而非参数口播
4. 结尾 CTA 一句话；全文口语化，单句不超过 20 字
5. 输出格式：hook(3秒)/痛点(5秒)/场景演示(15秒)/卖点收束(4秒)/CTA(3秒)
```

## 2. 分镜表 Prompt

```
基于以下脚本生成分镜表，逐镜输出：
镜号 | 时长(2-4秒) | 景别 | 画面描述(给AI绘画用的完整提示词，含人设/场景/光影/产品露出方式) | 台词/字幕 | 产品露出方式
要求：产品露出必须与 product-ref/structure.md 的关键结构一致，特写镜头标注具体部件。
```

## 3. 镜头一致性 Prompt（Gate 3 锚点）

```
以下为角色/场景锚点，后续所有镜头提示词必须复用以下一致性别状词：
[人设锚点]：28岁中国职业女性，及肩黑发，米白针织衫，明亮极简公寓，柔和自然光
[场景锚点]：客厅落地窗+浅灰沙发；厨房原木台面；卧室阳台绿植
[产品锚点]：{产品}（结构见 structure.md）
```

## 4. Hook 自检清单

- [ ] 3 秒内说完「给谁/什么问题/什么利益」
- [ ] 第一个画面有动态（倒水/开门/惊讶表情），禁止静态开头
- [ ] hook 文案与画面动作互相强化，不重复
