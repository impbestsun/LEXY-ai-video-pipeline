# 产品参考物料规范（Gate 4 · 产品保真第一关）

> 红线：**产品参考图只允许真实产品照片，禁止用 AI 生成画面充当产品参考。**
> 历史教训：产品扭曲/变形的根因就是把 AI 生成画面当成了产品参考图。

## 一、必备物料

| 物料 | 数量 | 要求 |
|---|---|---|
| 正面整机照 | ≥1 | 纯白/浅灰背景，产品居中占画面 60-80%，无遮挡 |
| 45°/侧面整机照 | ≥1 | 展示厚度与轮廓，logo 清晰可见 |
| 细节特写 | ≥1 | 按键/水箱/滚刷/屏幕等关键结构，微距清晰 |
| 结构描述文档 | 1 | `structure.md`：配色/材质/关键结构/相对比例 |

合计：**≥3 角度真实照片 + 1 份结构描述**方可进入 Gate5。

## 二、结构描述文档模板（structure.md）

```markdown
## 产品：碧云泉 C5 Plus 净水器
- 整体配色：主色 #XXXX（实测取色），辅助色，材质（亮面/哑光）
- 关键结构（按视觉权重排序）：
  1. 顶部出水口/触控面板（位置、形状、数量）
  2. 水箱窗（位置、透明度、水位刻度）
  3. 滤芯仓/底座（高度占比、分模线）
- logo：位置、朝向、颜色、最小清晰尺寸
- 常见易错点：出水嘴倾斜角度、底座分模线位置、logo 与面板间距
```

## 三、取色与校验

- 主色从真实照片取样（取色器/脚本取中位数色），不用宣传图（宣传图有色偏）
- Gate8 终检时，产品主色容差 ΔE < 8

## 四、归档

```
product-ref/
├── front.jpg        # 正面整机
├── angle45.jpg      # 45°/侧面
├── detail.jpg       # 细节特写
└── structure.md     # 结构描述
```

所有参考物料按课题归档，随 `trilogy/` 一起留痕，供复盘与一致性比对。
